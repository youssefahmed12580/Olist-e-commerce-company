E-Commerce Data Analysis

📊 Project Overview

This project focuses on analyzing e-commerce data to understand sales performance, customer behavior, and overall business performance.

The project was created using Power BI to transform raw data into an interactive dashboard and generate useful business insights.

🛠️ Tools Used

- Power BI
- Power Query
- DAX

📈 Dashboard

The dashboard provides an overview of the e-commerce business and allows users to explore the data interactively.

💡 Key Insights

The analysis helps identify sales trends, high-performing products and categories, and other important patterns in the e-commerce data.
